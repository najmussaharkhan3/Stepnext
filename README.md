# Stepnext

### B2B Logistics & Heavy Equipment Platform

StepNext Edge is a full-stack web application designed for the logistics and heavy equipment industry. It aims to provide a digital platform for connecting businesses with vehicle and equipment solutions through an accessible web interface.

## Overview

The project combines a modern React.js frontend with a Laravel backend to deliver a structured full-stack application.

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install frontend dependencies:

```bash
npm install
```

Start the frontend development server:

```bash
npm run dev
```

For backend setup, navigate to the Laravel project directory and follow the Laravel installation instructions.
